# B8A1 – Problem Solving with TypeScript & OOP

## Assignment Overview

This repository contains my solutions for the TypeScript and Object-Oriented Programming assignment.

The assignment focuses on practicing important TypeScript concepts, including:

- Basic types and optional parameters
- Union types and type narrowing
- Readonly tuples
- Generics and array operations
- Interfaces and object structures
- Classes, inheritance, and access modifiers
- Asynchronous programming with Promises
